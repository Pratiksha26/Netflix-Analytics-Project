# Netflix Analytics Project

## Project Overview

The Netflix Analytics Project is an interactive data analysis and visualization dashboard developed using Python, Pandas, Plotly, and Streamlit.

The dashboard provides meaningful insights into Netflix subscribers, viewing behavior, revenue, churn, subscription plans, countries, and device usage.

The project helps analyze customer behavior and business performance through interactive charts and visualizations.

## Key Features

- Interactive Netflix analytics dashboard
- Subscriber analysis
- Revenue analysis
- Customer behavior analysis
- Churn analysis
- Subscription plan analysis
- Country-wise analysis
- Device-wise analysis
- Viewing behavior analysis
- Interactive charts and visualizations
- Data cleaning and preprocessing
- Exploratory Data Analysis

## Technologies Used

- Python
- Pandas
- NumPy
- Plotly
- Streamlit
- Matplotlib
- CSV
- Exploratory Data Analysis
